# Huilapp_backend
Este repositorio está destinado a los archivos backend del aplicativo web Huilapp

# Flujo de trabajo
El flujo de trabajo se manejará por ramas, se deberá de crear una rama "feature/nombre_funcionalidad" para cualquier desarrollo
que se planea realizar, al terminar y testear el funcionamiento de la funcionalidad se debe de requerir un Pull request hacia la rama develop para su respectiva revisión.
